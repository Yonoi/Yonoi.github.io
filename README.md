# Yonoi.github.io

Personal profile site hosted on GitHub Pages.

**Live:** https://Yonoi.github.io

Plain HTML + CSS, no build step. Edit `index.html` / `style.css`, then `git push`.

## Content policy — IMPORTANT

This repository is the **PUBLIC layer only**. It is linked from a private CV, so anything committed here is world-readable.

Allowed:
- Career timeline: periods, role, research directions (no project names, no internal codenames)
- Accepted / published papers: venue, year, author role, a short abstract based on the public title, and public arXiv / PDF links
- Education, research interests, public contact channels (email, phone / WeChat, GitHub, Google Scholar)

Never publish here:
- Project names or project-level "what I did" descriptions
- Business metrics, uplift numbers, resource / machine counts, launch scope
- Performance ratings, internal org details
- Any CV content, CV files, or links to CV files

The CV (with all project details and metrics) is **confidential** and lives outside this repository, in the local `resume-project/` folder. Do not copy `*.pdf` / `*.md` resume files into this repo.
